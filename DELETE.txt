STEP 3 — Clearing/rejecting deposits (no UI anymore). In the Supabase
         SQL editor, run one of these with the request id from the
         deposit_requests table:

  select clear_deposit_request('<request-id>');   -- credits the user
  select reject_deposit_request('<request-id>');  -- rejects it

  To see pending requests:
  select id, user_id, asset, amount, network, created_at
  from deposit_requests where status = 'pending_clearance'
  order by created_at;

  To grant the QA user the reviewer role (needed for the functions):
  update public.profiles set role = 'admin'
  where email = 'meridian.clearance.20261002@example.com';
